# Engineering Process

Lifecycle: Need -> Requirement -> Architecture/ADR -> Component/Interface -> Work Item -> Code -> Verification -> Evidence -> Release.

Development uses Agile Kanban and progressive elaboration. Documentation is just-enough for the next safe decision, then updated from implementation/test evidence. Routine engineering can proceed autonomously; material scope, security posture, architecture lock-in, budget/procurement, and irreversible changes require escalation.

Definition of Done includes code review, automated tests, regression checks, traceability, documentation updates, and recovery/rollback considerations where relevant.
